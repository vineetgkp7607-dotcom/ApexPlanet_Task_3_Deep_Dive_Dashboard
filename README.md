# ApexPlanet Task 3: Deep-Dive Analysis & Interactive Dashboard

## Project Overview

This project focuses on deep-dive sales analysis, customer segmentation, KPI calculation, and interactive dashboard development using Python and Power BI.

## Project Objectives

* Calculate key business performance indicators (KPIs).
* Perform RFM analysis for customer behaviour.
* Segment customers based on their purchasing patterns.
* Analyse sales performance across products, categories, and months.
* Build an interactive Power BI dashboard.

## Tools & Technologies

* Python
* Pandas
* Power BI
* Microsoft Excel
* CSV Dataset

## Project Structure

* `data/` - Cleaned sales dataset.
* `python_scripts/` - Python scripts used for analysis.
* `powerbi/` - Interactive Power BI dashboard.
* `reports/` - KPI results and customer segmentation reports.
* `screenshots/` - Project screenshots.
